# Candidate-specific discovery evidence (#1660)

Status: local candidate only. Deploy the reviewed Web-owned `drizzle/0060_discovery_evidence.sql` before the dependent API. The migration adds nullable `ugcresearch.discovery_evidence` JSONB only; it does not backfill, alter review decisions, change permissions or update artist accounts. Live schema application and rollout require separate authorization. Web's additive client tolerates missing evidence from an older API.

New name-derived handle probes record the name used, matching page title and validated candidate URL. Matching-name web searches record the name, result URL and provider title (which may be absent). The snippet and diagnostic `reasoning` are not evidence. Stored version 1 observations carry `method`, `artistName`, `sourceUrl` and `observedTitle`; the read projection generates a deterministic method-specific `summary`. Names are bounded to 500 characters, URLs to 2048 and titles to 2000. Unsupported or malformed records return `evidence: null`, as do sources and non-research submissions. The evidence URL must match the suggestion URL with query and fragment removed. No title or matching handle proves ownership.

Existing pending, approved and rejected rows keep their original observations (or null) across rediscovery. Review decisions never overwrite the historical basis. Ownership checks, per-artist locks, transactions, and the rule that stronger automated matches cannot override a pending/reviewed suggestion are unchanged. The GET field is optional for rollout compatibility and nullable when observations are unavailable; it is not a confidence score. Clients show a needs-confirmation label only for still-pending research suggestions and escape observed text.

The API fixture `lib/artistLinkReview/__tests__/fixtures/0060_discovery_evidence.sql` is an exact copy of Web's migration for self-contained PGlite verification. Keep it byte-identical when changing the migration. Tests use isolated in-memory databases and synthetic profiles only; no real artist data or live schema was touched.
