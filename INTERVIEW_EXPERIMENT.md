## Running the experiment

This is an operator CLI, not a public route. It renders no UI and is not imported by active interview handlers. Node 24 and the locked pnpm dependencies are required. `tsx` is a pinned development dependency for this specific CLI.

```bash
pnpm interview:experiment --help
pnpm interview:experiment snapshot --env-file /private/path/production.env --environment production --artist-id <production-uuid> --expected-handle <connected-handle> --output /private/path/corpus.json
pnpm interview:experiment run --env-file /private/path/preview.env --corpus /private/path/corpus.json --output /private/path/new-review-directory
```

The snapshot reads through a repeatable-read, read-only transaction as `mnweb`. The operator selects the environment's connection; the environment label records that selection and is not an automatic host-to-environment classifier. Artist UUID and expected connected handle must match. Model runs read only the saved JSON and use AI Gateway; they do not connect to the database, scrape, save interview answers, or publish Lore. `--arm signals|context|connections` runs one arm. `--as-of <ISO>` filters both availability and publication. It is a current-snapshot cutoff simulation, **not a reconstructed historical deployment**: mutable posts lack version history and extracted baseline signals are derived now.

`--exclude-source <evidence-id>` can be repeated and requires `--exclusion-reason`. Exclusions remain in the private corpus audit. Production approval statuses are unchanged. Human judgment is needed when an approved source belongs to a namesake.

Each model call uses the existing Flash model by default, 512 Gemini thinking tokens (2,048 for revised preparation/review), at most 6,144 output tokens, a 45-second abort signal and no automatic retries. The main evidence packet is at most 48,000 UTF-8 bytes; a call's instruction/payload ceiling is 90,000 bytes. Other providers may ignore Gemini-specific thinking settings or unsupported temperatures; comparisons record the model rather than claiming identical internal reasoning. These are conservative text-size bounds, **not exact token counts** or a tokenizer. Actual provider usage and timing are recorded. A and B require at most two calls; C at most three. Failure stops the CLI, retaining earlier completed arm JSON; use `--arm` to investigate a failed arm in a new output directory.

Long sources are divided into overlapping original passages, with source group and offsets retained. Neither the generated Lore nor an index preview becomes independent evidence. Corrections and saved answers remain whole and pinned; a memory set too large for the budget fails explicitly. The navigation index uses short previews; selected sources are opened as original text. This selection still risks missing a relevant passage, and is a variable under evaluation, not a solved retrieval problem.

Short prompt IDs such as `e17` are reversible aliases for original UUID/offset references. Each selected passage keeps its original wording, source URL, dates and attribution; reports restore original IDs, and the complete captured source remains in the private corpus. Changing an ID does not summarize source text. The model still sees a bounded selection of passages, so preserved references alone do not guarantee that it saw every relevant qualification. Quotation validation permits layout-only whitespace differences for extracted PDFs and rejects changed words. The independent reviewer checks whole premises, attribution, corrections, redundancy and editorial value. Its acceptance is advisory.

Outputs are local files with mode 0600 in a mode-0700 directory: `questions.md` is blinded; `evidence.md` contains original references/excerpts; `methods.json` reveals arms and usage; `results.json` includes rejected drafts; `corpus.json` preserves the exact input. File creation refuses to overwrite existing reports. Keep all of them private and outside Git. Read the question sets before the method key.

Published replay withholds the originating source group from archive retrieval. The original turns, provenance and withheld source IDs stay in the report. This is a replay, not a newly received artist answer or a historical deployment reconstruction.
- The latest answer reaches research, preparation, drafting and checking. Replay is capped at 20 turns and 12,000 bytes; exceeding this fails explicitly rather than silently deleting conversation history. This is a short-session experiment, not yet durable production interview memory. Corrections and refusals must change the next move. Empty output is valid. Never fabricate an artist response or save replay turns to the database.
- The factual/editorial check explicitly examines already-answered content, temporal framing, source attribution, denied relationships, assumptions in the question, personal boundaries and response to the last answer. Mechanical quote validation remains mandatory; model approval remains advisory.
- A separate reusable `index` command reads every eligible Lore document in bounded overlapping sections, including all extracted text from the three Dutchyyy PDFs. It saves source-linked notes and section coverage in a private file bound to the artist, corpus hash, cutoff, model and index version. Coverage means text submitted successfully, not proof of understanding, PDF extraction completeness, or exhaustive notes. Exact originals remain authoritative. The index is never silently truncated or reused for a changed corpus. At most 64 reading calls; each has the existing limits. Failed indexing stops without claiming completeness. A private `.partial.json` checkpoint can be resumed with `--resume-memory <file>` into a new output path; already verified sections are not re-read. Non-verbatim individual notes are excluded and recorded, and a section whose proposed notes all fail validation stops the run. Whitespace-only layout differences resolve back to original character offsets. Stored quote prefixes are navigation anchors, never replacements for full source passages.
- Preparation and the prepared premise audit receive 2,048 thinking tokens (the other stages retain 512); this reasoning-budget change is part of the comparison bundle. The prepared audit records individual premises and temporal accuracy; unsupported or contradicted premises fail closed. Spoken questions over 40 words, multiple question marks, or invented double-quoted phrases of 12+ characters are mechanically rejected. After indexing, four measured interview calls at most: plan, prepare, draft, review. Existing per-call byte/output/time limits remain. Opened source context is capped at 48,000 bytes, or 60,000 including original replay answers. The planner receives the complete saved Lore notes and a bounded caption index; excessive note volume fails the overall call budget rather than being silently trimmed. No schema migration, new public route, production write, live interview/Lore prompt change or fabricated listening observation.

## October 5: select angles and preserve answer meaning

Pete authorized the next editorial priority after reviewing the results. Add an explicit `--editorial` option to the grounded CLI arm so the previous path remains reproducible. Reuse the same frozen archive, preparation, writer and critic models; record the extra editorial call as part of the comparison. No live route, model default, database or UI change.

- One full-original editorial call considers up to six candidate angles and selects at most three (one during a conversation). Each records original citations, a supported observation, what is already public, one unknown, the expected contribution of an answer, assumptions to avoid, and a selection/discard reason. Connections are marked direct, documented or hypothetical. Multiple sources are useful only when their relationship has meaning; a source-count quota must not force a connection. A current answer can supersede every prepared angle.
- The editorial call receives the complete eligible archive and exact current turns. With a conversation it also returns original anchors from the latest artist answer, its stated meaning, limits on interpretation and a proposed next move. Validate anchors against the actual latest answer, not against a generated paraphrase. Preserve this listening record and all candidate decisions privately.
- The writer opens originals cited by the selected candidate, retains pinned corrections/answers, and receives the chosen unknown and its constraints. Do not inherit a generic dossier question or force all research details into the spoken question. A clear simple question may be the result of deep preparation.
- Editorial review explicitly checks both the spoken question and its rationale/unknown for changes to the meaning of the latest answer. It must provide at least one verbatim latest-answer anchor, the interpretation being used, and whether it is faithful. A missing/unverifiable anchor or an unfaithful interpretation fails closed. Intention is not ability, preference is not an absolute rule, uncertainty is not a denial, and a single example is not a whole-career claim. Singular requests for an example do not by themselves assert that only one example exists.
- Existing citation, factual and one-question checks still apply. The extra selection call makes the maximum nine calls after reusable preparation (five for a conversation), with the same per-call bounds and one repair only. No automatic repeat-until-success loop. All attempts and decisions remain visible.

The expanded citation form is accepted only if both the source ID and passage ref exactly match the original lookup. For an explicit compound draft, the one repair can lock the first complete ask and regenerate only a matching rationale/unknown/citations; the final question still receives full semantic checks. This removes an extra ask, not source context, and does not invent a new question. Paid selection validation failures are retained in a private diagnostic file.
- A candidate with any fabricated or mismatched citation is discarded as a whole, with its rejected references and original selection recorded. Independently valid selected candidates can proceed.
